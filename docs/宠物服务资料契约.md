# 智能宠物产品多地区经营资料契约

本目录（`data/pet_ops/`）下的 12 个 CSV 由 `pet_service_region_ops.generator`
**确定性生成**，固定随机种子（20261124），可重复生成、字节级一致。全部标识、
地区、日期、金额均为虚构，不对应真实个人、企业或交易，也不构成业务数据或效果承诺。

文件编码为 UTF-8（带 BOM），金额使用十进制数值字符串，程序内以 `Decimal` 解析，
日期为定长 ISO 格式（`YYYY-MM-DD`），账期为 `YYYY-MM`。

## 文件与字段

| 文件 | 关键字段 | 说明 |
| --- | --- | --- |
| `households.csv` | `household_id`, `home_region`, `family_size`, `migrated_from`, `migrated_at`, `migration_state` | 家庭主数据；AU 末尾 3 个家庭在 2026-11 迁移至 US |
| `devices.csv` | `device_id`, `household_id`, `region`, `sku`, `installed_at`, `replaced_device_id`, `device_state` | 设备台账；`replaced_device_id` 非空表示换机，换机不新增续费分母 |
| `device_activity.csv` | `device_id`, `household_id`, `region`, `active_date`, `activity_minutes`, `connectivity_state`, `firmware` | 设备安装与活跃事件；在线不等于付费活跃 |
| `subscriptions.csv` | `subscription_id`, `household_id`, `region`, `plan`, `currency`, `period`, `local_price`, `is_family_plan`, `is_promo`, `subscription_state`, `fx_version` | 订阅账期链；促销周期 `is_promo=true` 不计入付费留存分母 |
| `refunds.csv` | `refund_id`, `subscription_id`, `region`, `currency`, `period`, `local_amount`, `refund_state`, `fx_version` | 退款；仅 `paid`/`approved` 冲减收入，`rejected` 不冲减 |
| `channel_settlements.csv` | `settlement_id`, `channel`, `region`, `currency`, `period`, `local_gross`, `local_fee`, `local_net`, `revenue_kind`, `fx_version`, `settlement_state` | 渠道分成与结算；`pending`/`disputed` 金额只保留本币，禁止并入美元净收入 |
| `service_requests.csv` | `request_id`, `region`, `household_id`, `device_id`, `period`, `opened_at`, `closed_at`, `request_state`, `handling_hours` | 服务请求与处理工时；未结案状态构成积压 |
| `supplier_contracts.csv` | `supplier_ref`, `region`, `contract_version`, `valid_from`, `valid_to`, `service_type`, `unit_cost_local`, `currency`, `capacity_hours`, `supplier_state` | 供应商合同版本；US 演示合同升级，JP 新版合同供应商被停用 |
| `service_obligations.csv` | `obligation_id`, `region`, `household_id`, `service_type`, `supplier_ref`, `contract_version`, `accepted_at`, `due_at`, `completion_state`, `fx_version` | 已承诺服务义务；按接受时合同版本与汇率版本双追溯 |
| `local_costs.csv` | `region`, `period`, `support_cost`, `returns_cost`, `partner_fee`, `capacity_hours`, `cost_version`, `currency`, `fx_version` | 本地服务成本与承接容量 |
| `fx_rates.csv` | `region`, `currency`, `fx_version`, `rate_to_usd`, `valid_from`, `valid_to`, `supersedes` | 汇率版本；US 在 2026-11 发布 FX-US-2 替代 FX-US-1 |
| `data_availability.csv` | `region`, `period`, `status`, `note` | 数据可用性声明：`final` 可比，`lagged`（延迟）/`migration`（迁移）不可比 |

## 状态语义（未知/处理中不得解释为零值或成功）

- 订阅：`active` / `renewed` / `churned` / `refunded` / `promo` / `cancelled`；
  付费基数只含 `active`、`renewed`、`churned` 且非促销的订阅，并按家庭去重。
- 结算：`settled` / `partial` 可计入可比净收入；`pending` / `disputed` 保留本币观察值。
- 退款：`paid` / `approved` 生效冲减；`rejected` 不冲减。
- 服务请求：`open` / `in-progress` / `escalated` 为未结案，计入积压。
- 义务：`accepted` / `in-progress` / `breached` 为未履约；暂停服务也不能撤销，
  历史义务按当时合同版本与汇率可追溯。
- 可用性：`lagged`（JP 2026-11，地区数据延迟）与 `migration`（AU 2026-11，
  家庭跨区迁移）账期不与 `final` 账期混算，报告中显式列出不可比范围。

## 合成场景与预期决策

| 地区 | 场景特征 | 预期决策 |
| --- | --- | --- |
| US | 留存 96%、附着率 100%、容量利用率低、成本达标；11 月汇率修订（影响在容忍阈值内） | 扩展（expand） |
| DE | 留存达标但 11 月渠道争议、容量利用率 100%、成本高 | 限量（limit） |
| JP | 留存低于阈值、11 月数据延迟、供应商停用、存在逾期义务 | 暂停（suspend） |
| AU | 促销转化与换机集中、经常性收入占比低、11 月家庭迁移不可比 | 限量（limit） |
