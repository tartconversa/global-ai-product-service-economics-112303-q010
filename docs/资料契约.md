# 资料契约

下列记录为确定性生成的本地合成资料，不含真实主体信息。不同文件通过标识字段关联，版本、生效时间、缺失状态和回执字段保留原始业务含义。

| 文件 | 字段 | 记录数 |
| --- | --- | ---: |
| `device_activity.csv` | `device_id`, `household_id`, `region`, `active_date`, `activity_minutes`, `connectivity_state`, `firmware` | 180 |
| `subscriptions.csv` | `subscription_id`, `household_id`, `region`, `plan`, `currency`, `period_start`, `period_end`, `subscription_state` | 120 |
| `settlements.csv` | `settlement_id`, `channel`, `region`, `currency`, `gross_amount`, `fee_amount`, `settled_amount`, `fx_version`, `settlement_state` | 48 |
| `regional_costs.csv` | `region`, `period`, `support_cost`, `returns_cost`, `partner_fee`, `capacity_hours`, `cost_version` | 32 |
| `service_obligations.csv` | `obligation_id`, `region`, `household_id`, `service_type`, `accepted_at`, `due_at`, `completion_state`, `supplier_ref` | 60 |

数据缺失、待审、争议和未回执均表示状态未知或处理中，不能解释成零值或成功。记录中的模拟日期用于复现跨期关系，不表示真实业务发生。
