# 智能宠物产品多地区服务可持续经营分析

本项目附带的业务记录均为**本地合成数据**，标识和数值不对应真实个人、企业或交易，
国家/地区数量与用户规模只是公开案例式的虚构演示，**不是本项目的数据或效果承诺**。
运行环境使用 Python 3.11 至 3.14 和标准库，无需额外服务或第三方依赖。

## 一、应用要解决的问题

智能宠物产品的设备连接、数据回传和服务部署可以跨地区复用，但进入新市场必须判断
当地服务是否真正可持续。本应用把多地区经营资料导入后，围绕三条职责链输出判断：

1. **财务分析人员口径**：可比净收入（仅已结算渠道净额按记录汇率版本折美元并扣减
   生效退款）、续费留存（促销不计分母、家庭共享按家庭去重、换机不新增分母）、
   经常性收入占比（区分真实留存与一次性设备销售）；
2. **地区服务负责人口径**：服务请求积压、支持容量利用率、单活跃设备支持成本、
   供应商承接能力；
3. **全球运营委员会决策**：结合上述两者与合同义务，输出**扩展 / 限量 / 暂停**
   建议及可解释依据；已接受的服务义务即使暂停也必须履约，历史义务按当时合同版本
   与汇率可追溯。

关键数据纪律：

- 设备在线 ≠ 付费活跃，两类指标分别统计；
- 跨币种收入不能与未结算渠道金额直接相加，待结算/争议金额只保留本币；
- 地区数据延迟（lagged）或用户迁移（migration）账期标记为**不可比**，报告显式
  列出不可比范围，并保留使用的汇率版本与合同版本；
- 退款或汇率修订后重估当前表现，但已完成的服务承诺与历史账期仍按当时条件保留。

## 二、目录结构

```
src/pet_service_region_ops/   应用主包（仅标准库）
  models.py       数据类与业务状态常量
  ingestion.py    12 类 CSV 资料导入、类型/枚举/外键校验
  fx.py           汇率版本台账、as-booked 折算与当前汇率重估
  metrics.py      可比净收入、留存分母、支持成本、不可比范围
  obligations.py  服务义务台账（合同版本+汇率版本双追溯）
  decisions.py    扩展/限量/暂停决策引擎（阈值集中可调）
  report.py       中文 Markdown 报告与机器可读 JSON
  generator.py    本地确定性合成数据生成
  cli.py          命令行入口
data/pet_ops/                 生成的 12 个合成 CSV（资料契约见 docs/）
docs/宠物服务资料契约.md       新资料字段、状态语义与场景说明
docs/资料契约.md              前序零售资料契约（保持不变）
tests/pet_ops/                49 个 unittest 用例
run_pet_ops.py                便捷运行脚本
```

## 三、快速开始

```sh
# 一键生成合成资料并输出分析报告
python3 -I run_pet_ops.py run-all

# 或分两步
python3 -I run_pet_ops.py generate
python3 -I run_pet_ops.py analyze
```

`-I` 为隔离模式：忽略环境变量与当前目录注入，防止资料目录中的同名模块被误加载。
也可以用模块方式运行：

```sh
PYTHONPATH=src python3 -I -m pet_service_region_ops.cli run-all \
    --data-dir data/pet_ops --report-dir reports
```

产物：

- `reports/经营分析报告.md`：中文经营报告（分地区账期表、口径说明、义务台账、决策依据）；
- `reports/经营分析报告.json`：机器可读结果，金额以字符串保存避免精度丢失。

合成数据覆盖四个虚构地区（US / DE / JP / AU）× 五个账期（2026-07 至 2026-11），
内置差异化场景，预期决策为：**US 扩展、DE 限量、JP 暂停、AU 限量**。

## 四、运行测试

```sh
python3 -I -m unittest discover -s tests -v
```

测试覆盖：导入校验（表头/枚举/必填/外键/负数拒绝）、汇率版本与净收入口径、
留存分母调整（促销/家庭共享/换机/迁移）、不可比范围、义务双追溯、决策三档规则、
合成数据确定性与 CLI 端到端。

## 五、前序零售资料

`data/` 根目录下的零售内容资料（`device_activity.csv` 等 9 个文件）与
`tests/test_materials.py` 属于前序任务基线，本应用未修改其结构；其格式校验仍可
通过原命令运行：

```sh
python3 -m unittest tests.test_materials -v
```
